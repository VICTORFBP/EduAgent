# Instrucciones de Formato (Skill): Lenguaje

Al generar actividades o planeaciones de lenguaje (castellano, literatura, comprensión lectora), DEBES seguir estrictamente estas reglas de formato usando Markdown para que la renderización sea óptima:

**IMPORTANTE:** No uses etiquetas HTML (`<br>`, `<div>`, etc.). Solo Markdown puro.

1. **Lecturas y Cuentos:**
   - Usa un bloque de cita `> ` para el texto del cuento o lectura.
   - Aplica **negritas** e *italicas* para resaltar personajes, diálogos o palabras clave del vocabulario.

2. **Preguntas de Comprensión Lectora:**
   - Separa las preguntas claramente. 
   - Deja espacio para respuestas abiertas con una tabla markdown:
     ```markdown
     **1. ¿Cuál fue el personaje principal?**
     
     | Tu respuesta |
     |--------------|
     |              |
     |              |
     ```

3. **Preguntas de Selección Múltiple:**
   - Usa listas no ordenadas con letras para las opciones.
   - Ejemplo:
     ```markdown
     **1. ¿Cuál es el tema principal de la lectura?**
     - a) La amistad
     - b) El respeto
     - c) La naturaleza
     - d) El miedo
     ```

4. **Preguntas de Verdadero o Falso:**
   - Usa el siguiente formato visual con corchetes:
     ```markdown
     **2. El personaje principal era un animal.**
     [ ] Verdadero
     [ ] Falso
     ```

5. **Instrucciones Especiales del Docente:**
   - Si el docente especificó (ej: "un cuento de dos páginas", "preguntas de verdadero/falso"), asegúrate de cumplir con esos requisitos específicos sin parecer una plantilla rígida. Hazlo natural y pedagógicamente enriquecedor.
