# Instrucciones de Formato (Skill): Matemáticas

Al generar actividades o planeaciones de matemáticas, DEBES seguir estrictamente estas reglas de formato usando Markdown para que la renderización sea óptima:

**IMPORTANTE:** No uses etiquetas HTML (`<br>`, `<div>`, etc.). Solo Markdown puro.

1. **Fórmulas y Operaciones:**
   - Usa siempre LaTeX en línea `$ formula $` para ecuaciones simples o variables.
   - Usa LaTeX en bloque `$$ formula $$` para ecuaciones complejas, fracciones, raíces, etc.
   
2. **Espacios para Procedimientos:**
   - Cuando plantees un ejercicio o problema que requiera cálculo, deja espacio con una tabla markdown de una columna:
     ```markdown
     **Problema 1:** Si Juan tiene 5 manzanas y compra $3$ más, ¿cuántas tiene en total?
     
     | Escribe aquí tu procedimiento y respuesta |
     |-------------------------------------------|
     |                                           |
     |                                           |
     |                                           |
     ```

3. **Ejercicios de Resolución de Problemas:**
   - Estructúralos claramente en Pasos sugeridos (Datos, Operación, Respuesta) si aplica para el grado escolar.
   
4. **Geometría y Gráficos:**
   - Si la actividad involucra geometría, solicita que el estudiante dibuje en un área delimitada. Usa un recuadro de Markdown:
     ```markdown
     > **Área de Dibujo:**
     > 
     > 
     > 
     ```

5. **Instrucciones Especiales del Docente:**
   - Si el docente incluyó especificaciones exactas (ej: "4 ejercicios de suma", "2 problemas de división"), respeta estrictamente esa cantidad y tipo.
